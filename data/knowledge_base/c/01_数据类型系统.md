# 模块 01：数据类型系统（Type System）

## 一、C 语言的数据类型总览

```
                      ┌── 基本类型 ── char, short, int, long, float, double, long double
                      │                 （signed / unsigned 修饰符）
        算术类型 ─────┤
        │             └── 枚举类型 ── enum
 类型 ──┤
        │             ┌── 数组类型 int a[10]
        │             ├── 结构体类型 struct Point { int x; int y; }
        聚合类型 ─────┤
        │             ├── 联合体类型 union Data { int i; float f; }
        │             └── 指针类型  int *p, char *s
        │
        └── void 类型（空类型，仅用于函数返回值和指针）
```

## 二、基本整型

### 1. 各类型的典型大小与范围

| 类型 | 典型大小 (字节) | 最小值 (signed) | 最大值 | 无符号最大值 |
|------|----------------|-----------------|--------|-------------|
| char | 1 | -128 | 127 | 255 |
| short | 2 | -32,768 | 32,767 | 65,535 |
| int | 4（现代平台） | -2,147,483,648 | 2,147,483,647 | 4,294,967,295 |
| long | 4 或 8（32/64位） | -2^31+1 或 -2^63+1 | 2^31-1 或 2^63-1 | 同上 |
| long long | 8 | -9×10^18 | 9×10^18 | 1.8×10^19 |

> 重要：C 标准只规定 `sizeof(char) = 1`，其他类型的具体大小由编译器和平台决定。要获取准确大小，用 `sizeof()`。

### 2. signed vs unsigned

```c
signed int a;    // 有符号（默认，等价于 int）
unsigned int b;  // 无符号（0 或正数）

unsigned int c = -1;  // 危险！会变成 4294967295（ UINT_MAX）
```

### 3. 浮点数

| 类型 | 典型大小 | 精度 | 范围 |
|------|---------|------|------|
| float | 4 字节 | ~7 位有效数字 | 10^-38 ~ 10^38 |
| double | 8 字节 | ~15 位有效数字 | 10^-308 ~ 10^308 |
| long double | 10/16 字节 | ~19 位 | 更广 |

```c
float pi_f = 3.14159f;     // 加 f 后缀，否则默认 double
double pi_d = 3.14159;
```

## 三、char 类型的特殊性

```c
// char 到底是 signed 还是 unsigned？由编译器决定！
char c = 0xA5;    // 在某些编译器上是 165（无符号），在另一些上是 -91（有符号）

// 正确的做法：显式声明
signed char   x;   // 存小整数（-128~127）
unsigned char y;   // 存字节/二进制数据（0~255）
char          z;   // 存字符串（编译器决定有无符号，但 ASCII 码都 < 128 所以不影响）
```

## 四、类型转换

### 1. 隐式转换（自动）
赋值或混合运算时，低精度 → 高精度自动转换：
```
char → short → int → unsigned → long → unsigned long → float → double → long double
```

```c
int a = 5;
double b = a;   // int 自动转 double
float c = 3.14;
double d = c;   // float 自动升 double

// 整数除法陷阱！
int i = 5, j = 2;
double r1 = i / j;     // r1 = 2.0（先整数除法得 2，再转 double）
double r2 = (double)i / j;  // r2 = 2.5（先转 double，再浮点除）
```

### 2. 显式转换（强制类型转换）
```c
int p = 300;
// 想要 300/7 = 42.857，不强制转就会得 42
double avg = (double)p / 7;

// 指针转整数（底层操作）
long addr = (long)ptr;
```

## 五、sizeof 运算符

`sizeof` 是**编译期**运算符，返回类型或变量占用的字节数，不是函数！

```c
int arr[] = {1, 2, 3, 4, 5};
int n = sizeof(arr) / sizeof(arr[0]);   // 元素个数 = 总字节 / 单元素字节
```

> 注意：在函数中，数组参数会退化成指针，此时 sizeof(arr) 返回的是**指针大小**（64 位机器为 8 字节），不是整个数组大小！

```c
void f(int arr[10]) {
    int n = sizeof(arr);   // ❌ n = 8（64位），不是 40！
}
```

## 六、常见坑点

1. **整数溢出**：`short s = 32767; s++;` → 变成 -32768（有符号溢出是未定义行为！）
2. **浮点精度**：`if (0.1 + 0.2 == 0.3)` → 永远为假，浮点要做近似比较 `|a-b| < 1e-9`
3. **unsigned/signed 混用**：`unsigned u = 5; int i = -1; if (u > i) ...` → 结果可能反直觉（i 被转成 unsigned 变成很大的正数）
