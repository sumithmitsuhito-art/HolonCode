# 模块 03：表达式与隐式转换

## 一、什么是表达式

表达式 = 运算符 + 操作数。每个表达式都有：
1. **值**：表达式计算出的结果
2. **类型**：结果的类型
3. **副作用**：是否修改了变量值（如 `a++` 有副作用，`a + 1` 没有）

## 二、常用算术转换（Usual Arithmetic Conversions）

当两个不同类型的操作数一起运算时，按以下"金字塔"转换：

```
 long double
      ↑
    double
      ↑
    float
      ↑
unsigned long long
      ↑
   long long
      ↑
 unsigned long ←┐
      ↑         │
    long        │ (int 比 unsigned 小的时候 unsigned 才胜出)
      ↑         │
unsigned int  ←┘
      ↑
     int ←── char, short（整型提升）
```

### 例
```c
char a = 5;           // a < int → 参与运算时先提升为 int
short b = 10;         // 同样整型提升
int r1 = a + b;       // 结果为 int

unsigned int u = 1;
int i = -1;
long r2 = u + i;      // i 被转 unsigned，变成 0xFFFFFFFF，结果 4294967296
```

## 三、整数提升

所有比 int "小" 的类型（char、short、枚举、位域）参与运算前先转成 int（或 unsigned int）：

```c
unsigned char a = 0xFF;   // 十进制 255
unsigned char b = 0xFF;
int s = a + b;            // s = 510（不是 254 或溢出）
```

## 四、溢出规则

| 情况 | 标准规定 |
|------|---------|
| 有符号整数溢出 | **未定义行为**（编译器可以做任何事：产生垃圾值、优化掉整个分支、崩溃……） |
| 无符号整数溢出 | 定义良好，按 2^N 模运算回绕 |

```c
// 有符号溢出 → 不要写！
int i = 2147483647;
i++;   // ❌ 未定义行为！

// 无符号溢出 → OK，回绕到 0
unsigned u = 4294967295u;
u++;   // u = 0 ✅
```

## 五、序列点与求值顺序

序列点 = 保证之前的副作用全部完成，之后的副作用还没开始。常见序列点：
- `;` 分号（完整语句结束）
- `&&`、`||`、`?:`、`,` 四个运算符的左操作数计算完成后
- 函数调用时，所有参数求值完进入函数前

```c
int i = 3;
int x = i++ * ++i;   // ❌ 未定义行为！两个 i 的副作用之间没有序列点
// 在不同编译器上可能得到 3*5=15、4*4=16 或其他值
```

**规则**：在同一个表达式中，不要两次修改同一个变量，也不要读一个被修改的变量。
