# 模块 07：指针完整体系

## 一、指针的本质

> **指针就是内存地址**。就像门牌号——门牌号不是房子本身，但你可以通过门牌号找到房子。

```c
int x = 42;
int *p = &x;    // p 保存的是 x 的地址（& 取地址运算符）
int y = *p;     // y = 42（* 解引用运算符：通过地址取值）

*p = 100;       // 通过指针修改 x，现在 x = 100
```

## 二、指针声明

```c
int *a;          // 指向 int 的指针
char *b;         // 指向 char 的指针
double **c;      // 指向 double 指针的指针（二级指针）
int *d[10];      // d 是指针数组：10 个 int* 元素
int (*e)[10];    // e 是数组指针：指向 10 个 int 的数组
int (*f)(int);   // f 是函数指针：指向 (int)->int 的函数
```

## 三、指针运算

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = &arr[0];

*(p + 0) = 10;   // arr[0]
*(p + 1) = 20;   // arr[1]（指针 + 整数 = 跳过 n 个单元，不是 n 字节！）

p++;             // p 指向下一个 int（地址加 4 字节）
int diff = p - arr;  // 指针相减：元素个数差 = 1

// 指针大小：在 64 位机器上都是 8 字节，不管它指向什么
size_t s1 = sizeof(int*);    // 8
size_t s2 = sizeof(char*);   // 8
size_t s3 = sizeof(double*); // 8
```

## 四、空指针与野指针

```c
int *p = NULL;   // 空指针：不指向任何合法对象（NULL 就是 0）
*p = 5;          // ❌ 空指针解引用 → 段错误（程序崩溃）

int *q;          // 野指针：未初始化，指向随机地址
*q = 10;         // ❌ 可能崩溃、也可能悄悄破坏内存（最危险）
```

## 五、指针与数组

```c
// 传数组给函数时，本质就是传首元素指针
void sort(int *a, int n) { }   // 等价 void sort(int a[], int n)
```

## 六、指针与 const

```c
const int *p;   // p 可变，*p 不可变（指针指向"只读"数据）
int *const q = &x;  // q 不可变，*q 可变（指针本身固定）
const int *const r = &x;  // 都不可变
```
