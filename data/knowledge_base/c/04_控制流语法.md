# 模块 04：控制流语法（Control Flow）

## 一、分支结构

### 1. if / else if / else
```c
int score = 85;
if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {       // 匹配到第一个为真的分支
    printf("B\n");
} else if (score >= 60) {
    printf("C\n");
} else {
    printf("D\n");
}
```

> **悬垂 else 陷阱**：else 总是和最近的 if 配对
> ```c
> if (a > 0)
>     if (b > 0)   x = 1;
> else             // ❌ 这个 else 属于 if (b > 0)，不是 if (a > 0)
>     x = -1;
> ```
> 解决：**永远用大括号**。

### 2. switch / case
```c
int op = 2;
switch (op) {
    case 1: printf("加\n"); break;    // break 跳出 switch
    case 2: printf("乘\n");           // 没 break → 穿透到下面的 case
    case 3: printf("这行也会被执行\n"); break;
    default: printf("未知\n");
}
```

- case 标签必须是**整型常量表达式**（不能是变量、字符串）
- 穿透是合法的（有时用来写"共享代码"），但一定要加注释说明是故意的

### 3. 三目运算符 `?:`
```c
int max = a > b ? a : b;    // a 大取 a，否则取 b

// 等价于
if (a > b) max = a;
else       max = b;
```

## 二、循环结构

### 1. for 循环
```c
// 三部分：初始化 ; 条件 ; 步进
for (int i = 0; i < 10; i++) {
    printf("%d ", i);
}

// 三部分都可以省略
for (;;) { }    // 死循环（等价 while (1)）
```

### 2. while 和 do-while
```c
// while：先判断再执行（可能一次都不执行）
while (n > 0) {
    sum += n;
    n--;
}

// do-while：先执行再判断（至少执行一次）
do {
    printf("请输入正数：");
    scanf("%d", &n);
} while (n <= 0);
```

## 三、break / continue / goto

| 语句 | 作用 |
|------|------|
| `break;` | 跳出**当前一层**循环 / switch |
| `continue;` | 跳过本轮循环剩余代码，进入下一轮条件判断 |
| `goto label;` | 跳转到同一函数内的标号（极少用） |

```c
// goto 唯一常见用法：统一错误处理
int f(void) {
    char *p = malloc(100);
    if (!p) goto error1;

    char *q = malloc(100);
    if (!q) goto error2;

    // ... 正常逻辑 ...
    free(q);
    free(p);
    return 0;

error2:
    free(p);
error1:
    return -1;
}
```
