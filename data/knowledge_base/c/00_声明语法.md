# 模块 00：声明语法（Declaration Syntax）

## 一、什么是"声明"

声明告诉编译器"某个东西叫什么名字、是什么类型"。它**不分配内存**，只是让编译器知道有这样一个实体存在。

> 比喻：声明就像"告诉别人有一个人叫张三，是个学生"；而"定义"则是真正把张三这个人创造出来、给他分配身份证和住址。

## 二、变量声明与定义

### 1. 基本语法
```c
// 声明 + 定义（分配内存）
int a;              // 定义一个 int 变量 a，默认值不确定
int b = 10;         // 定义 + 初始化

// 仅声明（不分配内存，用 extern）
extern int c;       // 声明 c 在别的文件里定义了
```

### 2. 初始化规则
```c
int x = 5;          // 直接初始化
int y; y = 5;       // 先定义再赋值（两步，性能略差）

int arr[5] = {1, 2, 3};  // 部分初始化，剩余元素为 0
int arr2[] = {1, 2, 3};  // 可省略数组大小，编译器自动推断为 3
```

### 3. 声明与定义的区别

| 概念 | 是否分配内存 | 出现次数 |
|------|-------------|---------|
| 声明 (declaration) | 否 | 可多次 |
| 定义 (definition) | 是 | 只能一次 |

```c
// 一个文件里可以多次声明同一个变量
extern int foo;
extern int foo;  // 没问题

// 但只能有一个定义
int foo;         // OK
// int foo = 5;  // 注释掉：重复定义会编译错误
```

## 三、标识符命名规则

标识符就是程序员给变量、函数、类型起的名字，必须遵守：
1. 只能由 **字母、数字、下划线** 组成
2. 第一个字符必须是 **字母或下划线**（不能是数字）
3. 区分大小写（`Foo` ≠ `foo`）
4. 不能是 C 语言关键字（`int`、`for`、`if` 等共 32 个）

```c
int _count;        // OK：下划线开头
int MyVar123;      // OK
int 123abc;        // ❌ 数字开头
int b - a;         // ❌ 含非法字符
int int;           // ❌ 与关键字重名
```

> 最佳实践：变量名用名词、函数名用动词 + 名词；全大写用于宏常量，避免以下划线 + 大写字母开头（C 标准保留）。

## 四、复杂声明解析（右左法则）

C 语言最"魔鬼"的部分之一。通用方法：**右左法则（Clockwise/Spiral Rule）**

从变量名开始，先往右看，再往左看，遇到括号就改变方向。

```c
// 例子 1：指针数组 vs 数组指针
int *p1[10];    // 往右到 [ ]，往左到 * → 指针的数组（10 个 int*）
int (*p2)[10];  // 括号里往右到头，往左到 * → 数组的指针（指向 10 int 的数组）

// 例子 2：函数指针
int (*fp)(int, double);
// 括号里往右到头，往左到 * → 指针；出去往右到 ( ) → 函数，参数 int,double；往左 int → 返回 int
// 所以 fp 是"指向 (int, double) -> int 函数"的指针

// 例子 3：最复杂的
char *(*(*f)())[10];
// f → (*f) 指针 → (*f)() 函数指针，无参返回 * → *[10] 指针数组，指向 char*
// 翻译：f 是"无参函数指针"，返回值是"指向 10 个 char* 数组的指针"
```

## 五、常见坑点

### 坑 1：忘了初始化
```c
int sum;
printf("%d\n", sum);  // ❌ 未初始化！值是不确定的垃圾数
```

### 坑 2：多次定义
```c
// file1.c
int count = 0;

// file2.c
int count;            // ❌ 两个定义，链接器报错 multiple definition
// 应该：extern int count;
```

### 坑 3：在 C89 中声明必须在块首
```c
void f(void) {
    int a = 1;
    a = a + 1;
    int b = 2;  // 在 C89（老标准）中报错：声明必须放在块开头
                // 在 C99 及以后 OK
}
```
