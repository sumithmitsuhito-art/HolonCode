# 模块 10：联合体（union）与枚举（enum）

## 一、联合体 union

联合体所有成员**共享同一块内存**，大小 = 最大成员的大小。同一时刻只能存一个成员。

```c
union Data {
    int i;
    float f;
    char s[8];
};

union Data d;
d.i = 0x3F800000;    // 按 int 写入
printf("%f\n", d.f);  // 又按 float 读出 → 1.0（正是浮点数的位模式）
// 常用于：1) 不同方式解释同一块内存  2) 节省空间的变体类型
```

## 二、枚举 enum

枚举是一组命名整型常量，增强可读性。

```c
enum Color {
    RED,     // 默认从 0 开始
    GREEN,   // 1
    BLUE     // 2
};

enum Weekday {
    MON = 1, TUE = 2, WED = 3, THU = 4, FRI = 5, SAT = 6, SUN = 7
};

enum Color c = BLUE;     // 实际值 2
```

> 在 C 中 enum 不做类型检查，可以赋任意整数给 enum 变量（不安全，但灵活）。
