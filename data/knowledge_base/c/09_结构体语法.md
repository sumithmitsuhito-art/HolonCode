# 模块 09：结构体语法

## 一、struct 的声明

```c
// 声明结构体类型
struct Point {
    int x;
    int y;
};

// 同时定义变量
struct Point p1;           // C 必须加 struct 关键字（C++ 可以省略）
struct Point p2 = {3, 4};  // 按顺序初始化

// 用字段名指定初始化（C99，推荐）
struct Point p3 = { .y = 5, .x = 1 };
```

## 二、typedef 简化写法

C 语言每次写 struct 很啰嗦，用 typedef：

```c
typedef struct {
    int x, y;
} Point;           // Point 现在是类型名

Point a, b;         // 不用再写 struct
```

## 三、访问字段

```c
Point p = {1, 2};
p.x = 10;                 // 直接访问用 .
printf("(%d,%d)\n", p.x, p.y);

Point *pp = &p;
pp->y = 20;               // 指针访问用 -> （等价于 (*pp).y）
```

## 四、结构体赋值

```c
Point a = {1, 2};
Point b = a;       // ✅ 可以直接赋值（逐字段拷贝）
```

## 五、结构体指针作为函数参数

传指针比传值更高效（不用复制整个结构体）：

```c
typedef struct { char name[32]; int score; } Student;

void print_stu(const Student *s) {
    printf("%s: %d\n", s->name, s->score);
}
```

## 六、嵌套结构体

```c
typedef struct {
    Point top_left;
    Point bottom_right;
} Rect;

Rect r = { {0, 0}, {10, 10} };
int w = r.bottom_right.x - r.top_left.x;   // 10
```
