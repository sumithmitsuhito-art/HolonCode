# 模块 16：函数指针与回调

## 一、函数指针的声明

```c
int add(int a, int b) { return a + b; }

// 声明一个与 add 匹配的函数指针
int (*fp)(int, int);   // 注意：(*fp) 括号不能少！否则是返回 int* 的函数声明

fp = add;              // 函数名自动退化为指针
int r = fp(2, 3);      // 调用（也可写 (*fp)(2,3)，等价）
```

## 二、作为参数：回调（Callback）

函数指针最经典的用法是**回调**：调用者把一个函数"传"给库函数，让它在合适的时候调用。

```c
/* 实现一个对数组任意两个元素进行比较的排序（qsort 原理） */
void sort(int *a, int n, int (*cmp)(int, int)) {
    for (int i = 0; i < n - 1; i++)
        for (int j = 0; j < n - i - 1; j++)
            if (cmp(a[j], a[j+1]) > 0) {
                int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
            }
}

// 定义不同比较策略
int asc(int a, int b)  { return a - b; }
int desc(int a, int b) { return b - a; }

int main() {
    int arr[] = {3, 1, 4, 1, 5, 9};
    sort(arr, 6, asc);     // 升序
    sort(arr, 6, desc);    // 降序
}
```

## 三、标准库 qsort

```c
#include <stdlib.h>
// 标准 qsort 比较函数签名：(const void*, const void*) -> int
int cmp_int(const void *a, const void *b) {
    return *(int*)a - *(int*)b;
}
qsort(arr, 6, sizeof(int), cmp_int);
```

## 四、函数指针数组：状态机 / 跳转表

```c
typedef void (*cmd_handler_t)(void);

void cmd_help(void)  { printf("help...\n"); }
void cmd_exit(void)  { exit(0); }

cmd_handler_t table[128];   // 一张跳转表

// 注册
table['h'] = cmd_help;
table['q'] = cmd_exit;

// 执行
if (table[key]) table[key]();
```
