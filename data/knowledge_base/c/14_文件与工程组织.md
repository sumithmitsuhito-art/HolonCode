# 模块 14：文件与工程组织

## 一、标准文件操作（`#include <stdio.h>`）

### 1. 打开 / 关闭
```c
FILE *fp;
fp = fopen("data.txt", "r");   // 只读。文件不存在返回 NULL
// 模式：r 读, w 写（清空）, a 追加, r+ 读写, b 二进制（如 "rb"）
if (!fp) { perror("fopen"); return -1; }

fclose(fp);   // 必须关，否则缓冲区可能没刷盘
```

### 2. 读写

```c
// 字符级
fgetc(fp);        // 读一个字符
fputc('A', fp);   // 写一个字符

// 行级
char line[256];
fgets(line, sizeof(line), fp);   // 读一行（含换行符）
fputs("hello\n", fp);           // 写一行

// 格式化
fprintf(fp, "count = %d\n", 10);
fscanf(fp, "%d", &n);

// 二进制整块读写（结构体、数组）
fwrite(&stu, sizeof(stu), 1, fp);
fread(&stu, sizeof(stu), 1, fp);
```

### 3. 判断 EOF
```c
while ((ch = fgetc(fp)) != EOF) { /* ... */ }
// feof(fp) 在上一次读 EOF 之后才返回真
```

## 二、头文件 / 源文件分工规范

```
project/
├── main.c              # 主函数
├── module1.c           # 实现 A 模块
├── module1.h           # 声明 A 模块的公共接口
├── module2.c
├── module2.h
└── Makefile            # 编译规则

规则：
- .h：放"可以给别人用的东西"——函数声明、宏、类型定义（typedef struct...）
- .c：放"具体实现"——函数定义、私有 static 函数、static 全局变量
- 头文件必须有头文件保护：#ifndef / #define / #endif
```

### 头文件模板 good.h
```c
#ifndef GOOD_H
#define GOOD_H

#ifdef __cplusplus
extern "C" {
#endif

// 公共接口
int add(int a, int b);

#ifdef __cplusplus
}
#endif

#endif /* GOOD_H */
```

## 三、多文件编译

```bash
# 分别编译为 .o，再链接
gcc -c main.c    -o main.o
gcc -c module1.c -o module1.o
gcc main.o module1.o -o myapp
./myapp
```
