# 模块 05：函数高级语法

## 一、函数的组成

```c
// 返回类型  函数名（参数列表）
long long  factorial(int n)  // ← 声明（原型）
{                            // ← 定义（函数体）
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

## 二、声明 vs 定义

- **声明（原型）**：告诉编译器"有这个函数，签名是 XXX"；放在头文件里
- **定义**：函数的具体实现（函数体）；放在 .c 文件里

```c
// good.h：声明
int add(int a, int b);

// good.c：定义
int add(int a, int b) { return a + b; }
```

如果不写声明就调用函数，老的 C89 会**隐式声明**（假设返回 int），可能导致严重 bug。

## 三、参数传递：值传递

C 语言所有参数都是**按值传递**——实参复制一份给形参。

```c
void swap_wrong(int a, int b) {
    int t = a; a = b; b = t;   // ❌ 只交换了副本，外面没变
}

void swap(int *a, int *b) {     // ✅ 传指针
    int t = *a; *a = *b; *b = t;
}

int main() {
    int x = 1, y = 2;
    swap_wrong(x, y);   // 调用后 x=1,y=2，没变！
    swap(&x, &y);       // 调用后 x=2,y=1 ✅
}
```

## 四、递归

递归 = 函数直接或间接调用自己。

### 递归三要素
1. **基准条件**：停止递归的情况
2. **递归条件**：把问题缩小
3. **向基准条件靠近**：每次调用都更接近结束

```c
// 最大公约数 GCD(a,b) = GCD(b, a%b), 基准 b==0 返回 a
int gcd(int a, int b) {
    if (b == 0) return a;          // 基准
    return gcd(b, a % b);          // 递归：规模缩小
}
```

### 递归的代价
- 每次调用都有**栈帧开销**（内存 + 时间），可能栈溢出
- 能用循环写的尽量用循环（递归只是写得好看）

## 五、数组作为参数

数组作为参数会**退化为指针**，函数内无法知道数组长度：

```c
void f(int arr[100]) {     // 100 完全没用！实际是 int *arr
    int n = sizeof(arr);   // ❌ 指针大小，不是数组大小
}

// 正确写法：传长度
void f2(int *arr, int len) {
    for (int i = 0; i < len; i++) { /* ... */ }
}
```
