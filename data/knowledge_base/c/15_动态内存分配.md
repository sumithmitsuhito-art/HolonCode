# 模块 15：动态内存分配（malloc / free）

堆（heap） = 动态内存区域，手动申请、手动释放。

## 一、四大函数（`#include <stdlib.h>`）

| 函数 | 作用 | 要点 |
|------|------|------|
| `malloc(n)` | 分配 n 字节 | **不会初始化**（值不确定），失败返回 NULL |
| `calloc(n, size)` | 分配 n×size 字节 | 所有字节初始化为 0 |
| `realloc(p, n)` | 把 p 指向的块重新分配为 n 字节 | 可能搬家，返回新地址；p=NULL 等价 malloc |
| `free(p)` | 释放 p 指向的块 | p=NULL 什么也不做；不要重复 free！ |

## 二、使用范式

```c
// 1. 申请（检查返回值！）
int *arr = (int*)malloc(10 * sizeof(int));
if (!arr) { fprintf(stderr, "内存不足\n"); exit(1); }

// 2. 使用
for (int i = 0; i < 10; i++) arr[i] = i;

// 3. 释放
free(arr);
arr = NULL;   // 好习惯：避免再误用（野指针）
```

## 三、常见内存 Bug

### 1. 内存泄漏（Memory Leak）
```c
void f(void) {
    char *p = malloc(100);
    // ... 忘了 free ...
}   // 函数结束 p 销毁，100 字节再也找不回来了
```

### 2. 悬垂指针（Dangling Pointer）
```c
char *p = malloc(100);
free(p);
strcpy(p, "hi");    // ❌ p 已经释放，写入非法！悬垂指针
```

### 3. 重复释放（Double Free）
```c
free(p);
free(p);    // ❌ 崩溃
```

### 4. 栈与堆混淆
```c
char *bad(void) {
    char buf[100];        // 栈上
    return buf;           // ❌ 返回栈地址！函数结束就销毁
                          // 应该改成 malloc 或 static
}
```

## 四、realloc 的正确用法

```c
// ❌ 错误：失败返回 NULL，原来的 p 就泄漏了
p = realloc(p, new_size);

// ✅ 正确：用临时指针
void *tmp = realloc(p, new_size);
if (!tmp) { free(p); return NULL; }   // 失败就释放原块
p = tmp;
```
