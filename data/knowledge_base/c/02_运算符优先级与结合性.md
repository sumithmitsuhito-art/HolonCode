# 模块 02：运算符优先级与结合性

## 一、优先级总表（从高到低，精简版）

| 优先级 | 运算符 | 结合性 | 例子 |
|--------|--------|--------|------|
| 1 | `()` `[]` `->` `.` | 左→右 | `a[0]` `p->x` `s.x` |
| 2 | `!` `~` `++` `--` `+` `-` `*` `&` `sizeof` `(类型)` | 右→左 | `!flag` `-a` `*p` `&x` |
| 3 | `*` `/` `%` | 左→右 | `a * b / c` |
| 4 | `+` `-` | 左→右 | `a + b - c` |
| 5 | `<<` `>>` | 左→右 | `1 << 8` |
| 6 | `<` `<=` `>` `>=` | 左→右 | `x < 100` |
| 7 | `==` `!=` | 左→右 | `flag == 0` |
| 8 | `&` | 左→右 | 按位与 |
| 9 | `^` | 左→右 | 按位异或 |
| 10 | `\|` | 左→右 | 按位或 |
| 11 | `&&` | 左→右 | `a && b` |
| 12 | `\|\|` | 左→右 | `a \|\| b` |
| 13 | `?:` (三目) | 右→左 | `a ? b : c` |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=` | 右→左 | `a += 5` |
| 15 | `,` (逗号) | 左→右 | `for(i=0,j=10; i<j; i++,j--)` |

> 记忆口诀：单 > 算 > 移 > 关 > 等 > 位 > 逻 > 三 > 赋 > 逗
> （单目 > 算术 > 移位 > 关系 > 等于 != == > 位运算 > 逻辑与或 > 三目 > 赋值 > 逗号）

## 二、结合性

相同优先级的运算符连续出现时，按"结合性"决定计算顺序：

```c
// 左结合：从左往右
a + b + c;     // (a + b) + c

// 右结合：从右往左
a = b = c;     // a = (b = c)
*p++;          // *(p++)（后缀++优先级高于*，右结合）
```

## 三、经典陷阱

### 陷阱 1：`==` 优先级高于 `&`
```c
// 本意：判断奇偶
int a = 5;
if (a & 1 == 0)       // ❌ 实际是 a & (1 == 0) = a & 0 = 0，恒为假
if ((a & 1) == 0)     // ✅ 正确写法
```

### 陷阱 2：指针自增
```c
int arr[] = {10, 20, 30};
int *p = arr;
int x = *p++;        // x = 10，p 指向 20（后缀++ 先取值再自增）
int y = *++p;        // y = 30（前缀++ 先自增再取值）
```

### 陷阱 3：逻辑运算符的短路
```c
int a = 0, b = 0;
if (a++ && b++) { }  // a=1, b=0（&& 左为假，直接短路，b++ 不执行）
if (a++ || b++) { }  // || 左为真，短路，b++ 不执行
```

## 四、最佳实践

- **不确定优先级时加括号**：括号让代码可读，比记忆所有优先级更可靠
- **避免写过于复杂的复合表达式**：拆写成多行、多个变量
