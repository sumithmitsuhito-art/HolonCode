# 模块 19：可变参数与常用标准库

## 一、可变参数（`<stdarg.h>`）

```c
#include <stdarg.h>
#include <stdio.h>

/* 对任意多个整数求和，第一个参数是个数 */
int sum(int count, ...) {
    va_list ap;           // 存储参数列表的指针
    va_start(ap, count);  // 从 count 之后开始
    int total = 0;
    for (int i = 0; i < count; i++) {
        total += va_arg(ap, int);   // 依次取参数（注意写类型）
    }
    va_end(ap);           // 清理
    return total;
}

int main() {
    printf("%d\n", sum(3, 10, 20, 30));   // 60
}
```

### 经典案例：自己实现 printf 迷你版

```c
void my_printf(const char *fmt, ...) {
    va_list ap;
    va_start(ap, fmt);
    while (*fmt) {
        if (*fmt == '%' && *(fmt + 1) == 'd') {
            int v = va_arg(ap, int);
            /* ... 输出 v ... */
            fmt++;
        } else {
            putchar(*fmt);
        }
        fmt++;
    }
    va_end(ap);
}
```

## 二、常用标准库速查

| 头文件 | 内容 |
|--------|------|
| `<stdio.h>` | printf/scanf、fopen/fclose、getchar/putchar |
| `<stdlib.h>` | malloc/calloc/realloc/free、atoi、atof、rand/srand、exit |
| `<string.h>` | strlen/strcpy/strcmp/strcat/memcpy/memset |
| `<ctype.h>` | isdigit、isalpha、isspace、tolower、toupper（**接收 unsigned char！**） |
| `<math.h>` | sqrt、pow、sin、log、fabs、floor、ceil（gcc 加 `-lm` 链接） |
| `<time.h>` | time、clock、difftime、strftime |
| `<stdint.h>` (C99) | 固定宽度类型：int32_t、uint64_t 等 |

## 三、注意：ctype 函数的参数

```c
char c = getchar();
if (islower(c)) { }  // ❌ 如果 c < 0（中文/二进制）会崩溃！
// 正确：传 (unsigned char)c
if (islower((unsigned char)c)) { }
```
