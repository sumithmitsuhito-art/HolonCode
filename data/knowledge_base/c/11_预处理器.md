# 模块 11：预处理器（Preprocessor）

预处理是编译第一步，处理所有 `#` 开头的指令，完成**文本替换**。

## 一、#include — 文件包含

```c
#include <stdio.h>    // 尖括号：系统/标准目录
#include "my.h"       // 双引号：先找当前目录，再找系统目录
```

## 二、#define — 宏定义

### 1. 宏常量
```c
#define PI 3.14159
#define MAX_SIZE 100
```

### 2. 宏函数
```c
#define SQR(x) ((x) * (x))           // 宏参数两边加括号！
#define MAX(a,b) ((a) > (b) ? (a) : (b))

int r = SQR(3 + 2);    // 展开后 ((3+2)*(3+2)) = 25
// 如果不加括号：SQR(x) x*x → 展开为 3+2*3+2 = 11，错！
```

### 3. 宏的坑

```c
// 坑 1：参数有副作用（++/-- 多次求值）
int i = 5;
MAX(i++, 10);    // 展开成 ((i++) > (10) ? (i++) : (10)) → i 自增两次！

// 坑 2：宏没有作用域，不区分命名空间；用 #undef 取消
#undef PI
```

## 三、条件编译

```c
// 最常见：头文件保护（防止重复包含）
#ifndef MY_HEADER_H
#define MY_HEADER_H

/* 头文件内容 */

#endif

// 判断平台
#ifdef _WIN32
    printf("Windows\n");
#elif __linux__
    printf("Linux\n");
#elif __APPLE__
    printf("macOS\n");
#endif

// Debug 宏
#ifdef DEBUG
    #define LOG(fmt, ...) printf(fmt, ##__VA_ARGS__)
#else
    #define LOG(fmt, ...) ((void)0)
#endif
```

## 四、# 和 ## 运算符

```c
// # → 把参数变成字符串字面量
#define STR(x) #x
const char *s = STR(hello);   // "hello"

// ## → 拼接两个标识符
#define DECLARE_VAR(type, n) type var_##n
DECLARE_VAR(int, count);      // 展开为：int var_count;
```
