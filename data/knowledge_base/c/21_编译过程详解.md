# 模块 21：编译过程详解

## 一、四大步骤

```
  hello.c ──预处理──▶ hello.i ──编译──▶ hello.s ──汇编──▶ hello.o ──链接──▶ hello
           (cpp)             (ccl)          (as)             (ld)
```

### 1. 预处理（Preprocess）
展开 `#include`、`#define`、`#ifdef` 等。

```bash
gcc -E hello.c -o hello.i    # 只做预处理，输出 .i
```

### 2. 编译（Compile）
把 C 翻译成**汇编代码**（文本）。

```bash
gcc -S hello.c -o hello.s    # 只编译不汇编，输出 .s
```

### 3. 汇编（Assemble）
把汇编翻译成**机器码**，生成目标文件 `.o` (Windows: `.obj`)。

```bash
gcc -c hello.c -o hello.o    # 只编译汇编不链接，输出 .o
# 用 objdump 看里面有什么
objdump -d hello.o
```

### 4. 链接（Link）
把多个 `.o` + 库（libc.a / .so）合并成可执行文件，解决符号引用。

```bash
gcc main.o util.o -o app    # 链接
```

## 二、gcc 常用选项

| 选项 | 作用 |
|------|------|
| `-o out` | 指定输出文件名 |
| `-c` | 只编译不链接 |
| `-E` | 只预处理 |
| `-S` | 只编译到汇编 |
| `-Wall -Wextra` | 打开几乎所有警告（**强烈建议**！） |
| `-Werror` | 警告当错误处理 |
| `-O0 / -O1 / -O2 / -O3` | 优化级别（调试用 -O0，发布用 -O2） |
| `-g` | 加调试信息（gdb 调试必须） |
| `-std=c99` / `-std=c11` | 指定 C 标准 |
| `-lxxx` | 链接库，如 `-lm`（数学库） |
| `-I dir` | 额外头文件搜索路径 |
| `-L dir` | 额外库文件搜索路径 |

推荐的教学编译命令：
```bash
gcc -std=c11 -Wall -Wextra -g -O0 main.c -o main
```

## 三、常见"链接错误"

```
undefined reference to `xxx`   → 声明了但找不到实现（没把正确的 .c / .a 加进来）
multiple definition of `xxx`   → 多个文件定义了同名全局变量/函数
```
