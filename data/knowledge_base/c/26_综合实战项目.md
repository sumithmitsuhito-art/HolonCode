# 模块 26：综合实战项目

本模块给出 5 个从简到难的完整项目建议，每个项目都覆盖了前面多个模块的知识点。

## 项目 1：命令行通讯录（入门）

**功能**：增删改查联系人（姓名、电话、邮箱），保存到文件，下次打开还在。

**知识点覆盖**：结构体、数组、字符串、文件读写、用户输入、菜单循环。

**建议结构**：
```c
typedef struct {
    char name[32];
    char phone[20];
    char email[64];
} Contact;

typedef struct {
    Contact data[256];
    int count;
} Book;

void book_load (Book *b, const char *path);
void book_save (const Book *b, const char *path);
void book_add  (Book *b);
void book_del  (Book *b);
void book_find (const Book *b);
void book_list (const Book *b);
```

## 项目 2：学生成绩管理系统（进阶）

**功能**：多班级、多科目、按分数排序、统计平均分/最高分/最低分、导出 CSV。

**知识点覆盖**：动态内存、qsort 函数指针回调、字符串处理、文件 I/O、模块化分文件。

## 项目 3：单链表实现的多项式计算器

**功能**：用单链表存 `3x^5 - 2x^3 + x` 这种多项式，支持加法、减法、乘法、求值。

**知识点覆盖**：单链表、动态内存、指针、复杂结构体操作、遍历合并。

## 项目 4：Mini Shell（进阶）

**功能**：打印提示符、读一行命令、按空格切参数、fork+exec 执行 `ls`、`cd`、`pwd`、`exit`、`|` 管道。

**知识点覆盖**：系统调用（fork/execvp/pipe/dup2/wait/chdir）、字符串切分、进程管理（仅 Linux/macOS 或 WSL）。

## 项目 5：C 语言编译器子集（终极）

**功能**：把只含 `+ - * / ( )`、整数变量的表达式编译成 x86-64 汇编（三地址代码）。

**知识点覆盖**：词法分析、递归下降解析、AST 构造、栈式代码生成、文件输出。

## 做题通用流程（强烈推荐养成习惯）

1. **读题**：把输入输出、约束、边界写下来
2. **设计数据结构**：用什么存？结构体怎么组织？
3. **先写接口再写实现**：先把函数签名写好（`.h` 一样的架子），再填空
4. **小步验证**：写一小段编译一次，打印调试，不要写完全部再编译
5. **边界测试**：空输入、0 个元素、最大输入、异常字符
6. **清理**：检查是否所有 malloc 都有 free，所有 fopen 都有 fclose
