# 模块 12：存储类别（Storage Class）

每个变量有两个属性：
- **类型**：int、float 等（存什么）
- **存储类别**：决定**生存期**（活多久）和**作用域**（在哪能看见）

## 一、四大存储类别

| 类别 | 关键字 | 生存期 | 作用域 | 默认初值 |
|------|--------|--------|--------|---------|
| 自动 | auto（默认） | 块内 | 块内 | 不确定 |
| 静态 | static | 整个程序 | 块内 或 整个文件（文件级） | 0 |
| 外部 | extern | 整个程序 | 整个程序（跨文件） | 0 |
| 寄存器 | register | 块内 | 块内 | 不确定 |

## 二、局部 vs 全局

```c
int g_count;     // 全局变量（默认 extern 链接），初始 0，活到程序结束

void f(void) {
    int a;       // auto，仅块内可见，值不确定
    static int s = 0;   // 静态局部：只初始化一次，下次调用保留上次的值
    a++;
    s++;
    printf("a=%d, s=%d\n", a, s);   // 第二次调用：a=随机值，s=2
}
```

## 三、static 的两种用法

```c
// 1) 函数内部 static 局部变量
int next_id(void) {
    static int id = 0;   // 只初始化一次
    return ++id;
}
// 调用 3 次：返回 1, 2, 3

// 2) 文件级 static：限制只在本文件可见（模块私有）
static void helper(void) { }   // 其他 .c 文件调不到
static int module_internal;    // 同理
```

## 四、extern 跨文件共享

```c
// a.c 定义
int global_counter = 0;
void reset_counter(void) { global_counter = 0; }

// b.c 使用
extern int global_counter;      // 声明在别处
extern void reset_counter(void);
```

> 不要在头文件里定义全局变量！多个 .c 包含会导致链接错误"multiple definition"。头文件里只写 `extern` 声明。
