# 模块 08：字符串处理语法

## 一、字符串在 C 里是什么

**C 没有独立的字符串类型！** 字符串 = 以 `\0` (NUL, 数值 0) 结尾的 char 数组。

```c
char s1[] = "hello";      // s1[6] = {'h','e','l','l','o','\0'}
char s2[6] = "hello";     // 同上，数组大小 6
char s3[] = {'h','i'};    // ❌ 不是字符串！少了 \0，当字符串用会越界

// 下面两个完全不同
const char *p = "world";  // p 指向只读段的字符串常量（不能写）
char buf[] = "world";     // buf 在栈上，内容可改
```

## 二、字符串长度 vs 数组大小

```c
char s[] = "abc";
strlen(s);   // 3   （\0 之前的字符数）
sizeof(s);   // 4   （含 \0 的总字节数）
```

## 三、常用标准库函数（需要 `#include <string.h>`）

| 函数 | 作用 | 注意 |
|------|------|------|
| `strlen(s)` | 长度 | 不含 `\0` |
| `strcpy(dst, src)` | 复制 | **dst 要有足够空间**，否则溢出 |
| `strncpy(dst, src, n)` | 安全复制 | 不一定补 `\0` |
| `strcat(dst, src)` | 拼接 | 同样可能溢出 |
| `strcmp(a, b)` | 比较 | <0/==0/>0 分别表示 a<b/==/> |
| `strstr(hay, ned)` | 查找子串 | 返回位置指针，没找到返回 NULL |
| `memcpy(dst, src, n)` | 内存复制 | 不处理 `\0`，按字节复制 n 字节 |

### ❌ 危险的 gets()
```c
char buf[100];
gets(buf);   // 永远不要用！无法限制输入长度（C11 已删除）
fgets(buf, sizeof(buf), stdin);   // ✅ 安全替代
```

## 四、自己实现 strlen

```c
int my_strlen(const char *s) {
    int n = 0;
    while (*s++) n++;   // 遇到 \0 停止
    return n;
}
```

## 五、常见坑

1. **char buf[3] = "abc";** → 没有空间放 `\0`，不是字符串
2. **strlen("")** = 0；**sizeof("")** = 1
3. **scanf("%s", buf)** → 遇到空格就停，且不限制长度可能溢出
