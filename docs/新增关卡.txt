二、填空题
下面程序把从终端读入的文本(用@作为文本结束标志)输出到一个名为bi.dat的新文件中，请填空。

c
#include "stdio.h"
FILE *fp;
main() {
    char ch;
    if((fp=fopen("bi.dat","w"))==NULL) exit(0);
    while((ch=getchar())!='@') fputc(ch, fp);
    fclose(fp);
}
